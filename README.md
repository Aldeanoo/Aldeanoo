### Lo que hago

Me enfoco en backend (PHP / Laravel / MySQL) y en la gestión directa del producto. Hablo con el cliente, entiendo dónde está perdiendo tiempo su equipo, diseño la base de datos y saco un sistema funcional que se pueda usar de inmediato.

Todos los proyectos en los que he trabajado tienen clientes y operaciones reales por detrás.

---

### Proyectos y sistemas que he desarrollado este año

* **Sistemas POS y Facturación:** Hechos a la medida del flujo de cada negocio (facturación rápida en ticket térmico, arqueos ciegos de caja, inventario multi-sucursal y control de bodegas).
* **Validador bancario de transferencias:** Sistema para verificar transferencias y comprobantes bancarios automáticamente, evitando fraudes y agilizando acreditaciones.
* **Plataforma de contratos y firmas digitales:** Para generar acuerdos legales y firmarlos digitalmente con registro de auditoría.
* **Marketplace de autos:** Portal para compra y venta de vehículos con filtros avanzados y gestión de prospectos.
* **Plataforma de loterías y sorteos:** Sistema en tiempo real para venta, control y validación automática de boletos ganadores.
* **Pasarelas de pago y tiendas online:** Integración de pagos con tarjeta y transferencia en tiendas virtuales optimizadas para vender rápido.
* **Landing pages para pauta publicitaria:** Páginas ultrarrápidas pensadas para soportar tráfico de anuncios y convertir visitas en clientes.
* **Servidores y despliegues:** Configuración y puesta a punto en servidores Linux (VPS y cPanel).
